## 3. 设计支柱 ×3

支柱是**决策过滤器**：任何新提案，若不服务于三条支柱之一，默认砍掉。

### 支柱一：准备是游戏，战斗是结算

**口号**：你不操作战斗，你设计战斗。

玩家的能动性全部前置到「出击之前」——配装、走词缀、点技能、调药剂。战斗是一次**可读的、自动结算的检验**：你的 build 对不对，650ms 一跳的战斗日志会诚实告诉你。这条支柱直接继承守夜人的自动战斗骨架，并把它从"偷懒"正名为"设计意图"。

**❌ 什么不做**
- ❌ 不做需要手速/反应的操作（QTE、闪避键、连招输入）
- ❌ 不做战斗中的实时微操按钮（"现在点这个技能"）
- ❌ 不做靠重复点击提速的机制（点击加速 = 惩罚不点的人）
- ❌ 不做玩家无法预判结果的纯随机胜负

### 支柱二：每次委托都带回一个决定

**口号**：3 分钟一局，必须有一次"选哪个"。

一次会话（3–10 分钟）结束时，玩家手里应该躺着一个**取舍**：这把新剑攻高但攻速崩、这件甲换了会破套装、这堆印屑是攒橙还是现在锻紫。数字变大不算反馈，**分叉才算**。这条支柱是防"自动战斗变成看进度条"的解药。

**❌ 什么不做**
- ❌ 不做纯数字自增的空转期（连续 10 场只涨经验不给决策）
- ❌ 不做需要玩家手动清理的背包垃圾潮（低价值掉落应可一键分解）
- ❌ 不做"唯一最优解"装备（出现主导策略即视为 bug，见 §9 红线）
- ❌ 不做需要查外部 wiki 才能做的决定（信息必须在 UI 内可得）

### 支柱三：越强越违法

**口号**：最强的法术，没有一个是合法的。

这是本作的**美学脊柱**，也是与守夜人最大的气质差异。守夜人是"你在对抗不可抗的天灾"，Arcanum 是"你在制度里往上爬，爬到顶发现制度才是敌人"。它落在具体内容上：稀有度 = 认证等级、词缀 = 官方批注、Boss 技能 = 夺取的禁咒、最强的智力武器叫**禁卷**、最高阶皮甲序列叫**无印**。

> ⚠️ **范围诚实声明**：MVP 阶段这条支柱**只体现在内容命名、掉落主题与叙事文本**上，不做机制化（不做通缉度、不做善恶值）。机制化列入 Later（见 §8）。这样做是为了避免 MVP 膨胀，同时保证美学一致性从第一天就在。

**❌ 什么不做**
- ❌ 不做善恶二选一的道德条（廉价且要双倍内容）
- ❌ 不做惩罚玩家变强的机制（"你太强了所以被削"= 反爽点）
- ❌ 不做需要玩家读长文才能 get 到的设定（世界观必须靠**物品名和技能名**传达）

## 4. MDA 分析

### 4.1 Mechanics（机制层 · 系统给了什么）

| 机制 | 来源 | 说明 |
|---|---|---|
| 自动回合战斗（650ms/tick） | 沿用 | 出手序由 spd 决定，技能按 cd 自动释放 |
| 7 装备槽 × 5 稀有度 × 词缀随机 | 沿用 | 稀有度决定词缀条数（0/1/2/3/4）与倍率（1.0→2.25） |
| 3 甲型 × N 阶的平行升级链 | 沿用 | 板/布/皮各一条命名序列 |
| 13 武器类型的「攻速—伤害」权衡网格 | 沿用 | 越重伤害越高攻速越低，绑定 str/agi/int |
| 技能 5 档（base/mid/high/aura/boss） | 沿用 | aura 为常驻被动不占施法轮次 |
| 武器—技能绑定 | 沿用 | 换武器即换技能池，是 build 分叉的主开关 |
| 分解 → 印屑 → 定向锻造 | 沿用 | 装备回收闭环，把"垃圾掉落"变成"资源" |
| 药剂能量制（击杀充能，非消耗品） | 沿用 | 免去补给管理，符合支柱一 |
| 5 势力据点递进 | 改造 | 每图 7 小怪 + 1 精英 + 1 Boss |
| Boss 唯一装备 + 专属技能书（各 ~3–5% 爆率） | 沿用 | 长线追逐目标 |

### 4.2 Dynamics（动态层 · 玩家实际会做什么）

这些是机制**碰撞后**涌现的行为，也是真正的游戏内容：

1. **Build 收敛 → 打破 → 再收敛**：玩家先随出身走一条属性线，掉到一件高稀有度异系武器后被迫重估（"我要不要转敏捷？"）。武器—技能绑定让转型有真实成本，因此这是个**有分量的决定**。
2. **推进 vs farm 的张力**：更高 tier 图掉更好的装备也更容易团灭。玩家会反复试探"我现在能不能上"——这是自动战斗游戏的**核心紧张感来源**，必须保护。
3. **分解 vs 装备的心理账户**：每件掉落都是"穿上"还是"熔了"。这是支柱二的主要载体，也是印屑经济的入口。
4. **套装的引力**：4 件套效果会让玩家**故意穿次优单件**去凑套。这是好的——它制造了自愿的非最优解。
5. **药剂词缀的隐性优化**：`instant/potency/killCharge` 三词缀让续航成为一条独立的优化轴，避免"只看攻击力"。

### 4.3 Aesthetics（美学层 · 目标体验）

按 MDA 八类美学，明确排序：

| 美学 | 权重 | 如何达成 |
|---|---|---|
| **Submission（消遣）** | ★★★ 主 | 自动战斗、低操作压力、可长时间开着 |
| **Challenge（挑战）** | ★★★ 主 | 地图 tier 门槛、Boss 检验 build |
| **Expression（表达）** | ★★☆ 次 | 甲型 = 站队、武器系 = 流派、套装选择 |
| **Discovery（发现）** | ★★☆ 次 | 词缀组合、套装效果、Boss 掉落、世界观碎片 |
| **Fantasy（扮演）** | ★☆☆ 辅 | 持牌者身份、势力序列命名 |
| Narrative（叙事） | ★☆☆ 辅 | 轻量，靠物品名与 Boss 前后对白承载 |
| **Fellowship（社交）** | ❌ 排除 | 纯单机硬约束 |
| **Sensation（感官）** | ❌ 弱化 | 单文件 HTML，无重表现力预算 |

#### Bartle 玩家类型定位

| 类型 | 是否目标 | 设计对策 |
|---|---|---|
| **Achiever（成就者）** | ✅ **主目标** | 必须有**可见的完成度靶子**：地图通关标记、Boss 首杀、套装集齐、稀有度图鉴。⚠️ 这是 MVP 最容易漏做的一块 |
| **Explorer（探索者）** | ✅ **次目标** | 系统深度即探索对象：词缀 × 套装 × 武器绑定的组合空间要足够大，且**不在 UI 里直说最优解** |
| Killer（杀手） | ❌ 不适用 | 无 PvP、无排行榜（后端约束） |
| Socializer（社交者） | ❌ 不适用 | 单机 |

> ⚠️ **单机的结构性风险**：砍掉 Killer 与 Socializer 后，游戏失去了两大留存引擎（攀比与社交）。**Achiever 的完成度系统必须做厚**来补偿——这是我给 V1 的强烈建议（图鉴/档案系统），也是 ❓Q2。

#### 自我决定论（SDT）三需求映射

| 需求 | 满足方式 | 风险 |
|---|---|---|
| **自主 Autonomy** | 出身 5 选 1；三条甲型序列 = 三种身份表达；武器系决定技能池；推进节奏自选（继续刷 or 上新图）；分解 vs 保留 | ✅ 覆盖充分 |
| **胜任 Competence** | 战斗日志即时反馈；清怪速度可感知；地图 tier 作为能力检验关；Boss 首杀作为里程碑 | ⚠️ 需要**明确的战力数值展示**（如面板 DPS 估算），否则玩家无法判断"我变强了没" |
| **关联 Relatedness** | 🔴 **单机最大缺口**。无真人。补偿方案：① AI 佣兵同伴（Party 骨架重写）② 委托人 NPC 与三大势力的关系文本 ③ Boss 作为"有名字有立场的人"而非纯怪物 | 🔴 MVP 只能靠 ③（Boss 拟人化 + 叙事文本）；①②列 V1 |

## 6. 世界观骨架

### 6.1 设定钩子（一句话）

> **魔法没有被消灭，它被上了锁、编了号、发了牌。你靠回收别人的违禁魔法过活。**

这不是"骑士与巨龙"，是**魔法官僚制**。核心冲突不是人对抗自然/邪神，而是**人对抗制度，以及人争夺魔法的分配权**。

### 6.2 背景

**卡兰德王国（Kingdom of Calend）**，晚期中世纪封建国家。

二百年前的「**洪流之年**」，无管制的施法引发灾变，三分之一人口消失，大地上留下数十处魔力过饱和的「**魔渊**」。灾后，王庭与法师们共同建立了 **秘典庭（The Arcanum）**——一个**登记、分级、发牌**的机构。

从此：
- 施法不违法，**未注册施法**才违法。
- 每一道合法法术都有编号，刻在施法者身上的「**印记**」里。
- 每一件魔法器物都要盖印。**无印之物即赃物**。

**玩家身份**：**持牌回收者**。你身上有秘典庭发的印记，你的工作是进入魔渊与违规区，**查封无印魔物与法器**，熔毁或上缴。你不是英雄，你是**拿执照的缉私者**。

> 💡 **这个钩子为什么好用**：它给游戏里每一个原本"因为是游戏所以这样"的机制都配了叙事解释——
> - 为什么自动战斗？→ 印记按注册协议自动释放法术，你不必手动施法（越权手动干预 = Later 的机制钩子）
> - 为什么疯狂捡装备？→ 你是来**查封**的，这是工作
> - 为什么能分解装备？→ 违禁品**依法熔毁**，熔出印屑
> - 为什么稀有度分五档？→ 那是**认证等级**
> - 为什么要打 Boss？→ 那是**通缉名单**上的人

### 6.3 地理分区（对应 `MAPS`，5 个据点）

关键设计：**五张图不是五个生物群系，是五个势力**。这是与守夜人（林→雪→树→火→虚空的自然递进）最本质的结构差异。递进逻辑是**违法层级越来越高，而你离制度核心越来越近**。

| # | 据点 | Tier | 势力 | 怪物族群 | 一句话 |
|---|---|---|---|---|---|
| 1 | **界桩荒野** | 0 | 无（边境） | **污染兽** | 王国最外圈的界桩，符文已褪色。泄漏的魔力把野兽拧成了别的东西 |
| 2 | **黑印集市** | 1 | 私法者 | **人型** | 地下黑市。走私犯、私法术士、雇佣兵。**第一次杀人而不是杀怪** |
| 3 | **缄默修道院** | 2 | 教团 | **亡灵 / 圣械** | 教团把"神迹"藏在圣骸里逃避登记。修士不说话，因为舌头是抵押物 |
| 4 | **灰铸厂** | 3 | 王庭军工 | **构装体** | 王庭合法地把魔法锻进兵器。这里的一切都有印，但印是自己盖给自己的 |
| 5 | **禁卷回廊** | 4 | 秘典庭 | **秘术造物** | 秘典庭的地下书库。查封了两百年的禁咒都在这。**发牌的人囤得最多** |

### 6.4 三大势力

| 势力 | 主张 | 对玩家 | 对应甲型序列 |
|---|---|---|---|
| **王庭** | 魔法应服务于王权与战争 | 雇主之一，给你军需 | **板甲** · 巡卫 → 执戟 → 圣印 → 王庭 |
| **秘典庭** | 魔法应被登记、分级、垄断 | 发牌人，也是最终反派 | **布甲** · 录事 → 持牌 → 首席 → 掌典 |
| **私法者** | 魔法属于所有人 | 你查封的对象，也可能是你的归宿 | **皮甲** · 走脚 → 私法 → 缄口 → **无印** |

> 💡 **甲型即站队**：玩家穿板甲/布甲/皮甲不只是数值选择，是**身份表达**（服务支柱三与 Expression 美学）。三条序列的最高阶分别是「王庭」「掌典」「**无印**」——无印是脱牌者，呼应主名候选 A。

### 6.5 冲突主线（三幕）

| 幕 | 据点 | 剧情 | 玩家心态转折 |
|---|---|---|---|
| **一幕：尽职** | 1–2 | 你是个称职的持牌者。清理边境污染兽，捣毁黑印集市。你相信制度 | "我在维护秩序" |
| **二幕：起疑** | 3–4 | 修道院的圣骸有秘典庭的封条；灰铸厂的违规品盖着合法印。**你发现有人在选择性执法** | "为什么有些无印之物不用查封？" |
| **三幕：摊牌** | 5 | 禁卷回廊。秘典庭两百年来查封的禁咒一件没毁，全在书库里。大掌典**塞维兰**告诉你：垄断即秩序 | "我要拿走执照，还是烧掉发牌处？" |

**结局定位**：MVP 只做到"打倒大掌典 + 一段结语文本"。多结局/分支列入 Later（❓Q2 相关）。

## 7. 与《守夜人·凋零纪元》的差异化对照

| 维度 | 守夜人是什么 | Arcanum 是什么 | 为什么这样改 |
|---|---|---|---|
| **题材基调** | 宇宙级熵增 / 末世凋零，神在死去，人只能守夜 | 中世纪王国的**魔法官僚制**，人在争夺魔法分配权 | 冲突从"不可抗的自然"变为"**可对抗的制度**"。给玩家能动性，也让 5 张图能按势力而非生物群系组织 |
| **主角身份** | 守夜人 —— 对抗凋零的哨兵，**被动防守** | 持牌回收者 —— 拿执照的缉私者，**主动出击** | 主动身份天然契合"接委托 → 出击 → 结算"的自动战斗循环；被动防守很难解释"为什么我一直在往外跑" |
| **成长主线** | 等级 + 装备，线性推进到虚空尽头 | **持牌等级晋升**（制度内爬升）→ 三幕转折 → 反噬制度 | 让数值成长挂上叙事意义。同样是"变强"，"晋升"比"变强"更有方向感 |
| **装备主题** | 通用奇幻序列（士兵/学徒/猎手） | **三势力序列**（王庭/持牌/私法），甲型 = 站队 | 把纯数值选择变成**身份表达**，补足单机缺失的 Expression 与自主感 |
| **稀有度语义** | 普通/优秀/稀有/史诗/传说（通用） | **无印/注籍/批准/特许/敕造**（认证等级） | 同一套颜色与倍率骨架，语义全换。玩家一看名字就在读世界观，零额外文本成本 |
| **技能体系主题** | 力/敏/智三系 + Boss 技 + 光环 | **骨架完全不动**，改为「注册咒文 / 私法咒文」；Boss 技 = **夺取的禁咒** | 严格遵守"骨架复用"约束。Boss 技从"专属掉落"升级为"你抢了他的违禁法术"，行为有了叙事解释 |
| **怪物族群** | 自然 + 宇宙（枯疫兽/孢子/魔像/虚空造物） | **五族群递进**：污染兽 → **人型** → 亡灵圣械 → 构装体 → 秘术造物 | **人型敌人是最大差异点**。守夜人几乎没有人形敌人；剑与魔法中世纪必须有"人对人"才立得住 |
| **地图结构** | 生物群系递进（林→雪→树→火→虚空） | **势力据点递进**（边境→黑市→修道院→军工→秘典庭） | 从"走得更远"变成"**捅得更深**"。每图换的是立场与敌人类型，不只是配色 |
| **材料/经济** | 五色碎片（普通/绿/蓝/紫/橙） | **五级印屑**（铅/铜/银/金/王印），熔毁查封品所得 | 保留 `DECOMP_YIELD` / `FORGE_RECIPES` 全部结构，只换语义。"分解"变成"**依法熔毁违禁品**" |
| **药剂** | 生命瓶 / 法力瓶（能量制，击杀充能） | **配给药剂**（秘典庭按持牌等级发放） | 保留能量制机制（免补给管理，符合支柱一），用"配给"解释为什么它不是消耗品 |
| **组队/联机** | 内建 Auth + WebSocket + 服务端协调组队 | 🔴 **整层移除**，`Party` 重写为本地 AI 佣兵 | **纯单机硬约束**。这是最大的一块工程改动，详见系统拆解 G 组 |
| **色调** | 冷调暗黑（青灰 / 幽紫 / 病绿） | **羊皮纸 + 蜡封红 + 旧金 + 墨黑**；冷光**只**用于魔法 | 让"魔法是被管制的异物"在视觉上成立：暖光是人间，冷光是违禁品 |

## 8. 范围分层

原则：**MVP 必须是一个人靠复用骨架能做完的量**。因为代码骨架复用，绝大部分工作量是**填数据表 + 改文案**，不是写系统。

### 🟢 MVP（必做 · 可玩闭环）

| 类别 | 内容量 | 说明 |
|---|---|---|
| 🔴 **剥离联机层** | Auth + MMO + 组队后端全删 | **阻塞项，必须最先做**。改为本地角色创建 |
| 地图 | **3 张**（界桩荒野 / 黑印集市 / 缄默修道院） | tier 0–2 |
| 怪物 | **27 个**（3 图 × [7 小怪 + 1 精英 + 1 Boss]） | 覆盖污染兽 / 人型 / 亡灵圣械三族群 |
| 装备槽 | 7 槽（全量沿用） | 无改动 |
| 稀有度 | 5 档（无印→敕造） | 仅换名 |
| 武器 | **13 类型**（全量重命名） | 数值网格沿用，改名成本极低 |
| 护甲 | 3 甲型 × **3 阶** | 阶数跟随地图数，V1 补第 4 阶 |
| 词缀 | 15 条（全量沿用，换名） | `AFFIX_POOL` 直接改 |
| 套装 | **2 套** | 王庭 / 私法各一，秘典庭套留 V1 |
| 技能 | **~25 个**：3 系 ×（base 3 + mid 2）+ 通用 3 + 光环 4 + Boss 3 | 高阶技留 V1 |
| Boss 掉落 | 3 组唯一装备 + 3 本 Boss 技能书 | 对应 3 个 Boss |
| 药剂 | 2 类 × **6 阶** + 3 词缀 | 阶数 = 图数 × 2 |
| 印屑经济 | **3 级印屑** + 分解 + 熔印坊定向锻造 | 完整闭环，不可砍 |
| 出身 | 5 个（重命名 + 叙事化） | 加成结构沿用 |
| 存档 | 本地多槽位 × 3 | 沿用，换命名空间 |
| UI | 左栏（地图 / 熔印坊 / 商店）+ 右栏（背包 / 技能 / 角色） | **组队 Tab 暂时隐藏** |
| 叙事 | 5 段：开场 + 3 个 Boss 前后对白 + 阶段结语 | 轻量，纯文本 |
| ⚠️ **战力面板** | 面板需显示可感知的战力估算 | 见 §4.3 胜任需求风险 |

> **MVP 完成度定义**：新玩家能创角 → 打穿 3 张图 → 拿到至少 1 件 Boss 唯一装备 → 凑出 1 套 2 件套 → 体验到完整的"掉落 → 取舍 → 熔毁 → 锻造"闭环。

## 9. 设计理论红线检查（自查）

| 红线 | 当前风险 | 处置 |
|---|---|---|
| **主导策略** | ⚠️ 中。武器网格中"最重武器"（战锤/秘典）单发伤害最高，若技能倍率不做补偿，重武器可能碾压 | Phase 2 GDD 必须验算「攻速 × 单发 × 技能 cd」的 DPS 等价性 |
| **主导策略（词缀）** | ⚠️ 中。`critDmg`（0.08–0.30）区间宽，可能远超其他词缀期望值 | Phase 2 做词缀期望值归一化 |
| **经济失衡** | ⚠️ 中。分解产出 vs 锻造消耗若比例失当，会出现"无脑分解一切"或"永远不锻造" | Phase 2 建印屑收支模型 |
| **认知过载** | 🟢 低。系统全部继承自已验证的骨架，玩家一次只面对一个新概念 | 保持。新增系统需过支柱审查 |
| **支柱漂移** | ⚠️ 中。支柱三"越强越违法"在 MVP 只做命名不做机制，**存在沦为纯装饰的风险** | 已在 §3 明确标注；V1 的委托板与 Later 的越权机制是其兑现路径 |
| 🔴 **单机 Relatedness 缺失** | 🔴 高。见 §4.3 | MVP 靠 Boss 拟人化硬撑；V1 必须上 AI 佣兵 |

## 10. 视觉锚点（给美术总监）

> 目标：让人一眼看出「这不是守夜人换皮」。守夜人是**冷调宇宙恐怖**，Arcanum 是**暖调文书官僚 + 中世纪石木质感**。

| # | 关键词 | 画面描述 |
|---|---|---|
| 1 | **羊皮纸与火漆印** | UI 基底从"暗色玻璃面板"换成**羊皮纸质感**；重要按钮/确认框带**火漆封蜡**视觉。这是全局第一识别符 |
| 2 | **蜡封红 · 旧金 · 墨黑** 三色主调 | 主色板明确对立守夜人的青灰/幽紫/病绿。红=印章，金=王权，黑=墨水 |
| 3 | **两套符文语言** | **合法魔法**：官方符文，规整、对齐、成行，像印刷体。**私法魔法**：歪斜、手写、涂改、盖不上章。这个对比是支柱三的主要视觉载体 |
| 4 | **纹章化装备图标** | 从守夜人的"圆形徽章底 + 线描图标"改为**盾徽构图**（heraldic shield），稀有度用**边框材质**（麻绳→黄铜→白银→鎏金→王室封蜡）而非只靠发光 |
| 5 | **五族群剪影语言** | 敌人一眼可辨：污染兽=低伏四足不对称 / 人型=直立持械 / 亡灵圣械=修长垂坠布料 / 构装体=方正块面直角 / 秘术造物=漂浮、无重心、由文字构成 |
| 6 | **石造与木构，而非自然废墟** | 场景锚点是**人造物**：界桩、市集棚架、修道院拱廊、锻炉、书架回廊。守夜人是自然侵蚀，Arcanum 是人类建筑 |
| 7 | **暖光为主，冷光即魔法** | 烛火/火把/熔炉的暖光是日常；**冷色光只在魔法出现时亮起**。强调"魔法是异物、是被管制的东西" |
| 8 | **文档感的 UI 元素** | 装备 tooltip 像**查封单**；技能像**许可证条目**（带编号）；分解确认像**销毁回执**。低成本、高辨识度 |

> 📌 稀有度色阶建议**保留玩家惯例**（灰→绿→蓝→紫→橙），但底衬换成羊皮纸而非深色玻璃。改色阶收益低、风险高。
