## 1. 视觉定位陈述

### 1.1 一句话定位

> **《敕造纪元·持牌者》是一份钉在石墙上的敕令：冷灰凿石的世界里，一张张羊皮公文被黄铜嵌条固定其上；秩序写在纸上，危险发生在石头之间——而魔法是唯一敢于同时照亮两者的光。**

### 1.2 三个视觉支柱

1. **石与纸（Stone & Vellum）** — 世界是冷灰石造的，制度是暖黄羊皮的。二者物理共存、界线分明，由黄铜构件缝合。这就是本作最独特的视觉签名（详见 §3）。
2. **纹章秩序（Heraldic Order）** — 界面构图遵循纹章分割逻辑（竖分/横分/斜分/四分），一切对称、可预期、有等级。这是"敕造/认证"世界观的视觉同构。
3. **锐利锻造（Forged Edge）** — 全局 `stroke-linejoin="miter"`，圆角极小（2–4px）。图形是被锤打切削出来的，不是被侵蚀出来的。

### 1.3 与《守夜人·凋零纪元》的视觉区分

| 维度 | 守夜人 · 凋零纪元 | **敕造纪元·持牌者** | 区分强度 |
|---|---|---|---|
| 底色制度 | 单一近黑 `#08090f` + 多层 radial 星空点 | **双层：冷石 `#171a20` / 羊皮 `#e6e0d2` 按区域分治**，无星空 | ⭐⭐⭐ |
| 明度基调 | 极暗（面板最亮 `#1a1e30`） | 石区中暗 + 纸区高亮，**全局明度跨度扩大 70 倍** | ⭐⭐⭐ |
| 色温 | 冷蓝黑 + 病态黄绿 | 冷石 vs 暖纸**对撞**，黄铜居中调停 | ⭐⭐⭐ |
| 线条端点 | `linecap/linejoin = round`（柔和有机） | `miter`（锐利锻造） | ⭐⭐⭐ |
| 面板圆角 | 14–20px 大圆角、胶囊按钮 | **4px 直角 + 尖拱 clip-path 切角** | ⭐⭐⭐ |
| 物品徽章 | 圆角方形 `badgeWrap` | **盾形（heater shield）clip-path 徽章** | ⭐⭐⭐ |

| 稀有度语义 | 普通/优秀/稀有/史诗/传说（通用 RPG） | **无印/注籍/批准/特许/敕造**（认证等级，世界观钩子） | ⭐⭐⭐ |
| 稀有度色 | 单套色值，仅适配近黑底 | **每阶双变体**，暗底/羊皮底各一套（§2.2） | ⭐⭐⭐ |
| 敌人构成 | 几乎无人形敌人（疫兽/孢菌/枯树精） | **人型敌人成为独立族群**（`humanoid_civil` 常民：雇佣兵/私法术士/走私犯/黑市掮客） | ⭐⭐⭐ |
| 玩家立绘 | 动漫风少年（棕发白 T 恤） | 中世纪冒险者，6.5 头身，硬朗剪影 | ⭐⭐ |
| 情绪 | 凋敝、压抑、无可挽回 | **秩序与违禁的张力；持牌与无印的分野** | ⭐⭐⭐ |

❌ **明令禁止的偷懒式区分**：仅替换 `:root` 色值而保留守夜人的大圆角、星空、round linejoin 与方形徽章。

#### B. 色序决策：**保留玩家惯例色序（灰→绿→蓝→紫→金），但全部重新取值**

**我的定案与理由**（团队要求我在此给出专业判断）：

采纳策划主张的**色相阶梯**，理由不是"降低认知成本"这一条，而是一条更硬的技术理由——

> **在双层底色制度下，明度阶梯会彻底失效，只有色相阶梯能跨域生存。**
>
> 明度阶梯（如我 v1.0 提议的黄铜明度序列）依赖"越高阶越亮"。这套逻辑在石区成立，但翻到羊皮区后**语义完全反转**：在 `#e6e0d2` 上，越亮的颜色越接近背景、越不可读，高阶反而消失。而色相阶梯的排序信息编码在**色相**上，色相不随底色反转，因此只需为每阶各准备一深一浅两个同色相变体，排序关系即可跨域保持。这是唯一能同时服务两种底色的方案。

同时我**否决**沿用骨架的原始色值（`#9aa0a6/#45d98e/#4a9eff/#b06bff/#ff9f3a`）：那五个值只针对近黑底 `#08090f` 调过，在 `--stone-2` 与羊皮区均未验证，且直接沿用会构成"换皮"观感。全部重取。

⚠️ **实测得出的关键结论**：相邻两阶之间的相互对比度只有 **1.01–1.36 : 1**。

> **稀有度的主传达通道是「盾形角饰计数」，颜色是辅助通道。** 这不是可访问性附加项，是基础设计。

## 3. 双层底色制度（Two-Realm System）★ 本版核心

### 3.1 域的划分

| 域 | 覆盖区域 | 底色 | 隐喻 |
|---|---|---|---|
| **石之域** Stone | 战斗区、怪物立绘背景、地图选择、BOSS 战 | `--stone-1/2/3` | **世界** —— 危险发生的地方 |
| **纸之域** Vellum | UI 面板、背包格、角色面板、装备栏、文本与战斗日志、设置 | `--vellum-0/1/2/3` | **制度** —— 记录与认证发生的地方 |
| **魔法冷光** Arcane | 法术特效、高阶装备辉光 | 高饱和学派色 | **唯一允许跨域的元素** |

**分域原则一句话**：**凡是"发生"的放石上，凡是"记录"的放纸上。** 这条原则可直接裁决任何新界面的归属，无需再逐个讨论。

### 3.2 交界处理：铜嵌条法则（Brass Batten Rule）

物理隐喻统一为：**一张羊皮公文被黄铜嵌条钉在石墙上。** 所有交界按此推导，五条规则：

| # | 规则 | CSS 实现 |
|---|---|---|
| 1 | **纸永远在上层，石永远在下层** | 纸区 `box-shadow: 0 3px 10px rgba(0,0,0,.45)` 投影落在石面上 |
| 2 | **交界必有 3px 黄铜嵌条**，纸石不得直接相触 | `border: 3px solid var(--brass)`（或单边 `border-top`） |
| 3 | 嵌条自带上暗下亮的倒角 | `box-shadow: inset 0 1px 0 rgba(0,0,0,.5), inset 0 -1px 0 rgba(255,255,255,.35)` |
| 4 | **只允许水平/垂直直线交界**，禁止斜切与不规则边 | 交界即 `border`，不用 `clip-path` |
| 5 | 纸区四周留石面边距 **≥12px**，不做全屏铺满 | `margin:12px` —— 保住"钉在墙上的一张纸"的读法 |
| 6 | 嵌条端点加 4px 黄铜铆钉 | 伪元素 `radial-gradient(circle, #e8c579 0%, #8a6420 70%)` |

✅ 这套法则的价值在于：它把"两种底色为什么能共存"这个观感问题，转化成了一个**有物理解释的构造问题**。玩家不会觉得是两个游戏拼在一起，而会觉得是同一个世界里的两种材质。

❌ **禁止**：渐变过渡（纸色渐变到石色）。会产生脏污的中间色，且破坏材质叙事。交界必须是硬边 + 嵌条。

### 3.3 跨域元素：魔法冷光

唯一允许无视嵌条、溢出到另一域的元素。规则：
- 法术辉光可从战斗区（石）溢出到相邻面板（纸）上，用 `filter: drop-shadow()` 实现，**不改变纸的底色**
- 高阶装备（特许/敕造）的徽章辉光在纸区同样可见
- 溢出的辉光**始终使用石区变体色**（高饱和亮色），因为它是"光"不是"墨"——光在纸上表现为提亮，符合物理直觉

### 3.4 稀有度色的双底适配方案 ★

#### A. 一条不可回避的数学结论

先给结论，再给推导：

> **不存在任何一个色值能同时在 `--stone-2` 与 `--vellum-2` 上达到 4.5 : 1。**

推导（实测）：
- 石区最劣底 `--stone-2` L=0.0305 → 要求前景 **L ≥ 0.3121**
- 纸区最劣底 `--vellum-2` L=0.6343 → 要求前景 **L ≤ 0.1021**
- **两区间不相交**（0.3121 > 0.1021）

所以"给稀有度配一套色值"这件事在双层底色制度下**是不可能完成的**。必须双变体。这不是保守设计，是硬约束。

#### B. 误用的代价（实测）

如果开发时取错变体，后果不是"不太好看"，而是**几乎不可见**：

| 阶 | 暗底变体误置于羊皮 | 羊皮变体误置于暗底 |
|---|---|---|
| 无印 | 1.63 ❌ | 1.63 ❌ |
| 注籍 | 1.45 ❌ | 1.73 ❌ |
| 批准 | 1.74 ❌ | 1.60 ❌ |
| 特许 | 1.88 ❌ | 1.58 ❌ |
| 敕造 | **1.38** ❌ | 1.65 ❌ |

全部在 1.4–1.9 区间 —— 相当于白纸上写浅黄，**完全不可读**。

#### C. 工程约定（强制）

```
rarColor(rarityKey, realm)     // realm: 'stone' | 'vellum'，无默认值
```

| 约定 | 说明 |
|---|---|
| ✅ `realm` 参数**必填，不设默认值** | 漏传直接抛错，让错误在开发期暴露，而不是在羊皮面板上静默消失 |
| ✅ 每个渲染函数在入口处显式声明所在域 | 如 `renderBagCell()` 内固定 `const R='vellum'` |
| ✅ 徽章组件 `badgeWrap(px, rarity, realm, ...)` 同样带域参数 | — |
| ❌ 禁止在 CSS 里写死稀有度色 | 必须走 CSS 变量 `--rar-{n}-d` / `--rar-{n}-p`，便于色盲模式整体切换 |

#### D. 敕造阶的特殊处理：火漆印

第 5 阶在纸区遇到一个表达难题——**"金色"在羊皮上必然要压暗才可读**（`#7d420a` 已是深赭），失去了"金"的贵气。

✅ **解法（同时也是最好的世界观表达）**：纸区的敕造徽章改用**火漆印**读法——
- 盾面填充 `--brass #c8963f`（作为**≥3px 的实体填充**，规避 2.02 的文本禁令）
- 盾形描边用 `#7d420a` 1.5px（提供轮廓对比）
- 徽章旁的**文字**用 `#7d420a`
- 加一圈 `--gules #b5342f` 的火漆外缘

这样"金"作为色块保留了贵气，"可读性"由深赭描边与文字承担，两者各司其职。且"敕令上盖火漆金印"本身就是本作世界观的核心意象。

### 6.3 三类护甲的形状差异

| 甲类 | Key | 势力 | 主色 / 描边 | 形状特征（path 层面） | 技术手段 |

## 9. 特效与反馈

### 9.1 伤害数字（石之域）

| 类型 | 颜色 | 字号 | 动画 |
|---|---|---|---|
| 普通物理 | `--ink` | 15px/600 | `translateY(0→-30px)` + `opacity(1→0)`，700ms ease-out |
| 元素伤害 | 学派石区变体 | 15px/600 | 同上 + `text-shadow: 0 0 6px` 同色 |
| **暴击** | `#ffd93d` | 22px/800 | `scale(0.6→1.5→1.15)` 前 180ms + 上飘；`text-shadow:0 0 10px #ffd93d,0 2px 0 #7a4a00` |
| 治疗 | `#7be0a4` | 15px/600 | 向上飘且**慢**（900ms），与伤害区分 |
| 闪避 / 格挡 | `--ink-dim` | 13px/500 | 横向抖动 ±3px ×3，无上飘 |
| 免疫 | `#9fc4e8` | 13px | 原地 scale 弹出 + 盾形符号 |

### 10.2 色盲模式备用色板（Comprehensive）

红绿色盲下最危险的冲突：**注籍绿 ↔ 敕造金**、**增益绿 ↔ 减益橙**。
策略：切换为**纯明度阶梯**，稀有度识别**完全交给角饰计数**。

| 阶 | 石区（on stone-2） | 纸区（on vellum-2） |
|---|---|---|
| 1 无印 | `#7d838b` · 3.41 ⚠️ | `#7e7869` · 2.86 ⚠️ |
| 2 注籍 | `#9aa1a9` · 5.00 ✅ | `#615b4e` · 4.39 ✅ |
| 3 批准 | `#b8bec6` · 6.97 ✅ | `#464135` · 6.62 ✅ |
| 4 特许 | `#d6dbe1` · 9.37 ✅ | `#2c281f` · 9.57 ✅ |
| 5 敕造 | `#ffffff` · 13.05 ✅ | `#0d0b07` · 12.81 ✅ |

⚠️ **第 1 阶（无印）豁免至 3:1 图形档** —— 它是丢弃档，且角饰"无装饰"本身已是最强识别信号。

📌 **必须记录的实测结论**：即使是专为区分而设计的明度阶梯，相邻两阶的相互对比度也只有 **1.34–1.53 : 1**（常规色相色板更低至 1.01–1.36）。这从数据上证明——
> **任何单纯依赖颜色的稀有度编码都是不可靠的。角饰计数必须是主通道。**
> 这条结论对 Standard 档同样成立，因此 #4（三重冗余）在 Standard 中就是必选项，而非 Comprehensive 的可选增强。
